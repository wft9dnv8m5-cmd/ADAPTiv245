Кейс из практики

Проект StaroSTATT

Веб-приложение для автоматизации работы старост. Заменило бумажные ведомости и ручной подсчет часов на единое облачное пространство.

  • Отметка посещаемости всей группы в один клик.
  • Автоматический расчет академических часов.
  • Выгрузка готовых CSV-отчетов.

Технологии:

JavaScript ES6+ HTML/CSS Firebase Database
